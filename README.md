# Учимся с Кларой

Сайт для родителей о том, как научить ребёнка читать. Рядом живёт приложение «Учимся читать с Кларой» (в App Store также «Учимся читать: азбука и слоги»). Автор: Константин Шкурко / Konstantin Shkurko.

Статический сайт на Astro. На хостинге вроде Beget нужен только HTML из папки `dist`, Node на сервере не требуется. Бэкенд на Rust, если понадобится, будет отдельным сервисом.

## Локально

Нужен Node 20 или новее.

```bash
cd klara-site
npm install
npm run dev
```

Откроется `http://localhost:4321`. Страница обновляется сама, когда правите файлы.

### WebStorm

1. File → Open → эта папка.
2. Дождитесь, пока WebStorm подхватит `package.json`.
3. Откройте `package.json`, слева от скрипта `dev` нажмите зелёный треугольник.
4. Либо встроенный Terminal: `npm run dev`.

Статьи лежат в `src/content/articles/` как обычный Markdown. Страницы в `src/pages/`. Общие тексты, ссылка на App Store и имя автора в `src/site.config.ts`.

## Сборка для хостинга

```bash
npm run build
```

В `dist/` будет готовый сайт. Эти файлы заливаются в корень сайта на Beget (или в `public_html`). Файл `.htaccess` уже копируется из `public/`.

Перед первой заливкой скопируйте `.env.example` в `.env` и поставьте будущий адрес:

```
SITE_URL=https://ваш-домен.ru
```

От этого адреса считаются canonical, sitemap, RSS и разметка для поиска.

## Полезные команды

| Команда | Зачем |
| --- | --- |
| `npm run dev` | Редактировать локально |
| `npm run build` | Собрать `dist/` и индекс поиска |
| `npm run preview` | Посмотреть собранный сайт |
| `npm run check` | Проверка TypeScript |
